# Baku Mobility MVP - AI Module

Bu repozitoriya Baku Mobility layihəsinin Süni İntellekt (AI), Məlumat Elmi (Data Science) və Məlumat Analitikası (Data Analytics) tərəfini ehtiva edir.

## Struktur (Folder Structure)

ML layihələrinin ən yaxşı təcrübələrinə əsasən qurulmuş struktur:
- `data/` - Datasetlər üçün qovluq (xam və işlənmiş).
- `notebooks/` - Eksperimentlər, analitika və Data Exploratory Analysis (EDA) üçün Jupyter Notebooklar.
- `src/` - Əsas model və script kodları.
- `api/` - Gələcəkdə modelləri mikroservis kimi təqdim etmək üçün FastAPI/Flask kodları.
- `models/` - Təlim edilmiş model çəkilərinin (.pkl, .h5) saxlanılması üçün.

## Texnologiya Steki
- Python 3.10+
- Pandas, Scikit-Learn
- Jupyter
- FastAPI (API üçün)
